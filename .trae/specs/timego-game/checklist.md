# Checklist

## 项目结构与依赖
- [ ] `timego/` 目录结构完整：`server.py`、`templates/index.html`、`static/style.css`、`static/script.js`、`requirements.txt`
- [ ] `requirements.txt` 包含 `flask`、`flask-socketio`、`eventlet`
- [ ] `python server.py` 可启动服务并访问页面

## 基础围棋规则
- [ ] 25×25 棋盘，黑先白后，黑贴 6.5 目
- [ ] 棋块识别与气计算正确
- [ ] 提子逻辑正确（移除无气对方块）
- [ ] 禁自杀（除非提子）生效
- [ ] 打劫（禁止全局同形再现）生效
- [ ] 棋谱记录坐标/颜色/落子后状态/当前轮

## 回溯权与时间债务
- [ ] 提对方 1 子获得 1 次回溯权（可累积）
- [ ] 消耗 1 次回溯权进行回溯代替常规落子
- [ ] 回溯目标限制为己方曾落子且未锁定的历史回合
- [ ] 透支上限 3 次，追偿点 = 当前手数 + 20
- [ ] 欠债期间提子优先还债
- [ ] 追偿点未还清跳过己方下一回合，每 10 手再触发
- [ ] 终局欠债领地扣除（欠债次数 × 3 目）

## 时痕子
- [ ] 回溯落子判定：空点放置 / 替换己方 / 触发分叉
- [ ] 时痕子不可被提（块无气时仅提普通子）
- [ ] 稳定期 0~20 全功能不可提
- [ ] 惰性期 21~40 不可提但不提供气且连接断开
- [ ] 湮灭 41+ 自动消失变空点
- [ ] 紧邻四格内回溯落子充能重置寿命
- [ ] 连锁消失（回溯过去提子致依赖子消失）
- [ ] 母手锁定时痕子立即消失
- [ ] 终局时痕子点与其围空计 0 目

## 时间线分叉与修复
- [ ] 回溯落子撞对方子触发分叉（新时间线继承，回溯子作普通子，原时间线冻结，切换战场）
- [ ] 新时间线吃掉病灶子触发修复（跳回原时间线，锁定第 1 手至分叉点，锁定吃病灶手，废弃其余，时痕子消失）
- [ ] 锁定节点禁止回溯

## 共振
- [ ] 落子/提子/修复后检测横/竖/斜 ≥3 枚时痕子
- [ ] 共振移除直线上所有棋子并标记永久空洞

## 终局与数目
- [ ] 终局条件齐全（认输 / 无合法着法且无可回溯 / 双方连续弃权并声明放弃回溯）
- [ ] 终局后禁止回溯
- [ ] 数目正确（领地归属、双活正常数目、时痕子 0 目、扣债务罚分、黑贴 6.5 目）

## 后端事件接口
- [ ] `connect`/`disconnect` 会话维护
- [ ] `make_move` / `time_back` / `pass_turn` / `resign` / `declare_end` 处理
- [ ] `update_state` 广播包含棋盘/元数据/历史/时间线树
- [ ] 人机模式轮到 AI 自动落子

## MCTS AI

- [ ] 手工特征评估（领地/厚势/时痕价值/资源/共振威胁）
- [ ] 每步 800~1000 次模拟，UCB1 + 快速走子贪婪随机
- [ ] 模拟忽略分叉与修复，时痕子直接放置

- [ ] 时间线树状图（活跃/冻结/锁定）
